# Two Hands Together

An original eight-bar C-major piano study at 80 BPM, released under CC0-1.0.
The right-hand melody starts at middle C (C4); sustained left-hand triads
remain below C4. The game displays these on treble and bass staves.

Add this directory as a song-library folder, or copy the Harmonicon artist
folder into your song library. The chart and synthesized backing track
are in Harmonicon/Two Hands Together/song/.

The piano score currently divides notes at C4; it does not infer crossing
hands or preserve independently authored hand/voice assignments.
