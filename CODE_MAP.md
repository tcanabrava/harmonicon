## Where to look first

| Question | Start at |
|---|---|
| What a song/chart *is*, its schema checks | `harmonicon-core` `chart.rs`, `chart_check.rs`; loader in `harmonicon-song` `song/loader.rs` |
| An instrument's model (pitches, positions, lanes) | `harmonicon-core` `instrument.rs` (`InstrumentModel`, `Instrument`), `instrument/*.rs` |
| Which instrument a part is played on | `harmonicon-app` `EffectiveHarmonica::{harp_for, instrument_for}` |
| Scoring a note | `harmonicon-gameplay` `gameplay/judge.rs`; pure maths in core `scoring` |
| The clock | `harmonicon-gameplay` `gameplay/clock.rs` |
| Jam Session screen | `harmonicon-jam` `jam/session.rs` (setup), `hole_map.rs` (harmonica map, `JamGuide`), `instrument_map.rs` (other instruments), `improv.rs` (tally) |
| The notation staff | `harmonicon-ui` `music_score/mod.rs` (live rebuild), `staff_window.rs`, `full_score.rs` (pause score), pure maths in `notation.rs` |
| Settings / profile files on disk | `harmonicon-platform` `paths.rs` (`load_json_over_defaults`), `settings.rs`; `harmonicon-app` `profile.rs` |
| Pack download / update | `harmonicon-packs` `git.rs` (`install`, `check_tree`), `retained_songs.rs`; game side `harmonicon-platform` `content_packs.rs`, `content_sync.rs` |
| Lessons per instrument | `harmonicon-song` `lessons/catalog.rs` (loads one instrument), `lessons/validate.rs` (what `validate-pack` checks) |
| Song picker | `harmonicon-menu` `menu/pages/artist_list.rs` (+ `artist_list/`) |
| Keyboard focus, modals | `harmonicon-ui` `dialogs/keyboard_nav.rs`; gameplay screens get their `TabGroup` from `GameplayRoot` (`gameplay/state.rs`) |
| Localization lookups | `harmonicon-platform` `localization/mod.rs`; strings in `assets/locales/<lang>/main/ui.ftl` (all three locales) |
| Source lints (localization, messages, `PointerClick`, `SceneRoot`) | root `build.rs`; its tests run with `rustc --edition 2024 --test build.rs -o target/build-rs-tests && target/build-rs-tests` |

## Cheap ways to check work

- Test one crate, not the workspace: `cargo test --release --features dev -p <crate>`. `harmonicon-core` has no Bevy and takes seconds.
- Clippy one crate: `cargo clippy --release --features dev -p <crate> --all-targets --no-deps -- -D warnings`.
- Running the game binary directly (not through `cargo run`) needs `BEVY_ASSET_ROOT=<checkout>`, or Bevy looks for `assets/` beside the executable and every label shows its raw key.
- A running `--features dev` build is driven over BRP with `scripts/brpctl.py` (`buttons`, `click`, `shot`, `jam <artist> <song>`).
